# Customer Retention & Churn Analysis Dashboard

## Project Overview
This project analyzes customer churn behavior and retention trends using Power BI.

## Tools Used
- Power BI
- Excel

## KPIs
- Total Customers
- Churn Customers
- Churn Rate

## Key Insights
- Monthly contract users churn more frequently
- UPI users show highest churn
- Customers with higher monthly charges are more likely to churn

## Recommendations
- Encourage long-term subscriptions
- Improve customer retention strategies
- Reduce churn among high-risk customers

 ## Conclusion

This project analyzed customer churn and retention patterns using Power BI. The dashboard identified important factors affecting churn such as contract type, payment method, tenure, and monthly charges, helping generate useful business insights for improving customer retention.
